ҚАЙДА ОРНАЛАСТЫРУ КЕРЕК?
Онлайн жинау функциясы міндетті түрде NETLIFY FUNCTIONS ретінде жариялануы тиіс.
Ең сенімді жол — GitHub репозиторийін Netlify-ға 'Import from Git' арқылы қосу.
ZIP-ті алдын ала ашыңыз, репозиторийдің түбіріне барлық файлды салыңыз.
Содан кейін Netlify: Add new project → Import an existing project → GitHub.
Build command: npm run build; Publish directory: . (netlify.toml файлында жазылған).
Netlify package.json бойынша @netlify/blobs кітапханасын орнатады.
Жарияланған сайтқа кіріп, «Нәтижелер» бөлімімен тексеріңіз.
